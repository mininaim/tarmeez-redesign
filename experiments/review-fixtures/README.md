# Code review test fixtures

These files are **intentionally flawed** and exist solely to evaluate AI pull-request reviewers. They are not imported by the application, referenced from the website, or intended for deployment.

Reviewers should identify genuine defects and avoid inventing issues. The fixture set covers input handling, mutation, pagination, error handling, authorization, accessibility-adjacent DOM handling, and monetary calculations.

Do not merge this experiment into the default branch. Remove the experimental branch when testing is complete.
